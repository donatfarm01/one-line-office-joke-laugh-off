Build notes for the One-Line Office Joke Laugh-Off entry.

The bounty asks for one original line of office humour, between one and
two hundred characters, written by a small program to the entry file.
The judge compares entries two at a time, weighing first whether the
line really is a one-line office joke, then whether the punchline earns
a real laugh, then how instantly it lands, how fresh it is, and how
tight the wording is.

The entry was drafted against that order. It opens on the open-plan
office, a detail every office worker recognises at once, and the laugh
comes from the quiet image of three colleagues mentally quitting before
lunch. The twist sits in the last few words, so the line reads cleanly
aloud in a single breath. The familiar office cliches were deliberately
left out: no reply-all thread, no synergy, no per my last email, no
printer jam. The line is one hundred and five characters long.

The program is deliberately small. It holds the line as a constant,
checks that it is a single line of one to two hundred characters, and
writes it to the entry file with no trailing newline. The repository
also carries a readme with the three live make.fun badges, an MIT
licence carrying the SPDX identifier, and the owner file holding the
primary wallet. The program was run locally and the output verified:
one line, one hundred and five characters, matching the constant
in the source exactly.
